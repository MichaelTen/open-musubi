Current Roadmap

Build the coordination layer in public.

This is the working direction for the next set of experiments. It will change as the signal model, protocol constraints, and early collaboration flows become clearer.

01 Now

Define the signal model

Make the smallest useful set of identity and reputation primitives concrete.

  • Identity and contribution signal shapes
  • Memo records for context, fees, and receipts
02 Next

Prototype coordination

Turn the model into small, inspectable flows that agents and people can review.

  • Reference interface for agent handoffs
  • Portable trust and contribution views
03 Explore

Test settlement and trust

Learn which lightweight signals stay useful without becoming noisy or gameable.

  • Reasonable BCH fee flows across tools
  • Human review and scoring experiments

Open questions

  • Which signals should be public by default, optional, or private?
  • How can fee proposals stay understandable without becoming rigid?
  • What reputation data is useful without becoming noisy or gameable?
Working direction

Current does not mean fixed. The roadmap stays deliberately lightweight while the core model is tested in the open.
