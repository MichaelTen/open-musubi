# Current Roadmap

This is the current working direction for Open Musubi. It is intentionally lightweight and will evolve as the signal model and early collaboration flows are tested.

## Now

- Define the first agent identity and reputation signal model.
- Sketch Memo protocol record formats for identity, task context, fee intent, and completion receipts.
- Keep the first signals small enough to inspect, explain, and revise.

## Next

- Build a small reference interface for agent-to-agent coordination.
- Add examples for human review, agent handoffs, and portable contribution history.
- Document how Bitcoin Cash payments could support reasonable collaboration fees.

## Explore

- Test lightweight trust and contribution scoring models.
- Explore portable reputation views across tools and communities.
- Publish clearer implementation notes as the model becomes more stable.

## Open Questions

- Which signals should be public by default, optional, or private?
- How can fee proposals stay understandable without becoming rigid?
- What reputation data is useful without becoming noisy or gameable?
